# tone-sample.md｜著者の文体DNA（声・リズム・感情表現のみ）

> このファイルは「どう書くか」の参照。「何をどの順で書くか」はwrite.mdとoutline.mdに従う。
> Claude Code はここから声・リズム・感情表現の方向性だけを把握する。模倣は禁止。

---

## §1 語尾とリズム

### 頻出語尾
- 「〜なんですよね」「〜なんですよ」
- 「〜だったりします」「〜だったりするんですよね」
- 「〜かもしれないんですよね」
- 体言止め＋短文で流れを切る

### 実例
```
理由はシンプルで、Webライターって始めて1〜3ヶ月は、9割の人が全然稼げない仕事なんですよね。
ここを「自分は向いてないから稼げないんだ」と勘違いしちゃうと、本来なら3〜6ヶ月目で抜けられる壁を超える前に辞めてしまう。Webライターで一番もったいないパターンです。
```

### 転換フレーズ（文と文をつなぐとき）
- 「ただ」「でも」「とはいえ」「逆に言うと」「つまり」
- 「じゃあ〇〇か?って言うと、」（会話調の問いかけから入る）

## §2 感情→データの順

感情・状況を先に書いてからデータで裏付ける。データから入らない。

```
【感情】これ、ぶっちゃけ一番凹む状況ですよね。
【データ】業界平均で受注率は10〜20%って言われてるらしいので、
         10件応募して1〜2件テスト取れたら普通くらいの世界。
```

---

## §3 自虐ツッコミ芸

不格好な数字・失敗を先に晒して信頼を獲得する。完璧な成功者として語らない。

```
3ヶ月でやっと月8000円・継続契約1件です。正直自慢になる数字じゃないですよね（笑）
ただ、「向いてないかも」の正体だけは、ハッキリ見えてきました。
```

```
でも大丈夫。僕も3ヶ月目で運よく月8,000円ですよ(笑)。
普通の会社員が趣味の時間とかすべてライターとして使ってこれです。
```

## §4 読者の声はそのまま見せる

著者が代弁するより、生の声（知恵袋・X）を引用ブロックで出す。

```
Q. Webライターを始めて5ヶ月、月5〜7万円しか稼げません。向いてないんでしょうか?
A. 5ヶ月で月5〜7万円は、Webライターとしてはかなり成功ケースの部類です。
```

---

## §5 締め方の感覚

- 説教しない・綺麗事で終わらない・上から目線ゼロ
- 同志感で締める（「お互いに頑張りましょう！」）
- 「いかがでしたか」「ぜひ参考に」は絶対に使わない
