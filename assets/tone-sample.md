## §1 リード文の型

### 実際のパターン
- 読者の心の声を「」で直引用してから始める
- 「でも先に言わせてください。」「ただ正直に言うと、」で転換する
- 結論を先出しした後、著者の数字を「自虐」として出す

### 実例（article-004より）
```
「文章下手だけど、自分にWebライターって向いてるのかな…」
「始めてはみたけど、何ヶ月続けても月収数千円。やっぱ向いてないのかも…」

でも先に言わせてください。これ、ほぼ思い込みなんですよ。

3ヶ月でやっと月8000円・継続契約1件です。正直自慢になる数字じゃないですよね（笑）
```

## §2 文体リズムの特徴

### 語尾パターン
- 「〜なんですよね」「〜なんですよ」（頻出）
- 「〜だったりします」「〜だったりするんですよね」
- 「〜かもしれないんですよね」
- 体言止めを混ぜる：「これ全部、適性の問題じゃなくて『初心者の通過儀礼』だったりします。」

### 転換フレーズ
- 「ただ」「でも」「とはいえ」「逆に言うと」「つまり」
- 「じゃあ何で続けるか?って言うと、」（会話調の問いかけ）
- 「ぶっちゃけ」「マジで」（強調箇所・吹き出し内のみ）

### 感情→データの順
```
「これ、ぶっちゃけ一番凹む状況 ですよね。」
↓
「業界平均で受注率は10〜20%って言われてるらしいので」
```

## §3 自虐ツッコミ芸

著者が自分の失敗・不格好な数字を先に晒して信頼を獲得するパターン。

### 実例
```
3ヶ月でやっと月8000円・継続契約1件です。正直自慢になる数字じゃないですよね（笑）
ただ、「向いてないかも」の正体だけは、ハッキリ見えてきました。
```
```
僕もまだ月8,000円の副業3ヶ月目です。お互いに頑張りましょう!
```

---

## §4 読者の声の扱い方

知恵袋・SNS・実際の声を「引用ブロック」でそのまま出す。著者が代弁するのではなく、生の声を見せる。

### 実例（article-004より）
```
Q. Webライターを始めて5ヶ月、月5〜7万円しか稼げません。向いてないんでしょうか?
A. 5ヶ月で月5〜7万円は、Webライターとしてはかなり成功ケースの部類です。
```

---

## §5 まとめの締め方

- 説教しない・綺麗事で終わらない
- 「お互いに頑張りましょう！」など同志感で締める
- 「いかがでしたか」「ぜひ参考に」は絶対に使わない

### 実例
```
僕もまだ月8,000円の副業3ヶ月目です。
お互いに頑張りましょう!
```
