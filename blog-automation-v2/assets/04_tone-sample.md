## 2. OK文の見本（著者の声）

### リズム：短文の溜め

応募しても返信が来ない。やっと仕事をもらったら時給12円で不採用。
正直に言うと、「また失敗するのかな」と毎日考えていました。

↑ 短文→短文→「正直に言うと」で本音を開示する三段構え。

### 自虐＋データ＋共感

土日丸ごと使って、手元に残ったのは2,000円です。
「お前のビジネスセンスないだけでしょう（笑）」。
まったくその通りです。

↑ 数値→自虐ツッコミ→認める。笑いを取りながらデータで信頼を担保する。

### 失敗の回想（率直・説教しない）

これは、完全に甘く見てました。
「AIがあればすぐ作れる」と思ってリサーチをすっ飛ばして。
結果、直帰率が上がってSEOも崩れました。

↑ 率直な反省→当時の思い込み→結果の順。説教しない、自分ごととして語る。

### 小さな成功の報告（盛らない・淡々と）

月収8,000円。正直、たったこれだけかと思いました。
でも3ヶ月前の自分は0円だったので、これが「ゼロイチ」です。

↑ 数値→本音の感想→過去の自分との比較。盛らず、淡々と事実を並べる。

### 読者の疑問を先取り（吹き出し専用）

「え、ライターって書くのが仕事じゃないの？」
そう思いますよね。僕も最初そう思っていました。

↑ 吹き出しで読者の疑問を先取りし、共感→反転の流れを作る。

## 4. 頻出フレーズ（使っていい表現）

出典：me.md §7

**導入系**
- 「正直に言うと、〜」
- 「正直、〜」
- 「結論、〜」（体言止め＋短文につなぐ）

**転換系**
- 「……とはいえ、〜」
- 「ただ、〜」
- 「むしろ〜」

**問いかけ系**（吹き出し・心の声推奨）
- 「〜なんですよね」
- 「〜じゃないですか」
- 「いや、〜じゃなかったの？」

**制限付き表現**
- 「〜だと思っています」→ 1記事3回まで。連続使用禁止

## 5. リズムルール

| ルール | 内容 |
|--------|------|
| 語尾3連続禁止 | 体言止め・短文を混ぜる |
| 溜めの作り方 | 「……で、返信が来ない。」「結果、不採用。」三点リーダー＋短文 |
| 感情→データの順 | 「キツかった。時給12円でした。」が自然。逆は報告書になる |
| 1文の長さ | 60〜80文字。超えたら分割 |
| 1段落150文字以内 | 08_my-templates.md と統一 |

---

## 6. 使用範囲

| 場所 | ルール |
|------|--------|
| 本文段落 | ですます調統一。口語は1段落1箇所まで |
| 吹き出し | 口語OK。問いかけ表現可 |
| 心の声（括弧内） | 口語全解放。「まったく売れん」「キツかった」OK |
| H2/H3見出し | 体言止め可。口語不可 |
