# /research コマンド｜キーワードリサーチ手順書

## 入力

```
/research [メインKW]
```

例：`/research Webライター 向いてない`

---

## Step 1: サジェストKWの取得

以下のURLをWebFetchで取得する。

```
https://suggestqueries.google.com/complete/search?q=[KWをURLエンコード]&hl=ja&client=firefox
```

取得できない場合はユーザーに「Googleで[KW]と入力したときのサジェスト一覧を貼り付けてください」と依頼する。

抽出項目：
- サジェストKW一覧（共起語・関連語）
- メインKWとの意味的な違い・距離感

---

## Step 2: 検索意図の4階層分析

KWとサジェストKW・知恵袋の声をもとに以下4層で分析する。

### Lv1：顕在ニーズ
KWをそのまま読んだときに想定される表面的な欲求。

### Lv2：潜在ニーズ
言葉にしていない本当の欲求。以下の2パターンを必ず検証する。
- パターンA：「向いてない」と肯定してほしい層（撤退の言い訳探し）
- パターンB：「向いてない」を否定してほしい層（背中を押されたい）

### Lv3：深層ニーズ
人生レベルで抱えている根本課題。自己評価の不安・過去の挫折経験・孤独など。

### Lv4：検索の瞬間に起きていたであろう具体シーン
ペルソナがこのKWを叩いた、まさにその瞬間の状況を5パターン以上推定する。

---

## Step 3: ユーザーリサーチ（知恵袋 + SNS）

### Yahoo知恵袋

```
https://chiebukuro.yahoo.co.jp/search?p=[KWをURLエンコード]&search=1
```

抽出項目：
- 質問タイトル（読者の生の悩み）
- 回答の傾向（何が解決策として挙げられているか）
- 感情ワード（「しんどい」「向いてないかも」「やめようか」など）

### X（Twitter）

```
https://twitter.com/search?q=[KWをURLエンコード]&f=live
```

抽出項目：
- リアルな感情吐露（ポジティブ・ネガティブ両方）
- よく使われる言い回し・スラング
- 共感が集まっている投稿のパターン

知恵袋・SNSは「競合記事」にカウントしない。ユーザーリサーチの別枠として扱う。

---

## Step 4: 競合記事のWebFetch

ユーザーにGoogleで「[メインKW]」を検索し、上位URLを提供するよう依頼する。

```
「[KW]」をGoogleで検索して、表示された上位20件のURLを貼り付けてください。
除外フィルターを適用して分析対象10本を選定します。
```

### 除外ルール（以下に該当する記事は分析対象から除外する）

1. タイトルにKW（「向いてない」「向かない」「向いていない」のいずれか）が含まれない記事
2. noteドメインの記事（note.com / note.mu など）
3. SNS投稿（X/Twitter、Instagram、Facebook、TikTok）
4. YouTube動画ページ
5. 知恵袋・教えてgooなどQ&Aサイト（Step 3で別枠扱い済み）

**除外ルールを通過した記事10本**を分析対象とする。

### 各記事から抽出する項目

| 抽出項目 | 内容 |
|---------|------|
| タイトル | 記事タイトル |
| H2・H3構成 | 見出し一覧 |
| 文字数（概算） | 記事ボリューム |
| 強み | 他の競合より優れている点 |
| 弱み | 一次情報の欠如・抽象的な内容・解決策なしなど |
| CTAの有無 | アフィリエイト・内部リンクの配置 |

---

## Step 5: me.mdと照合（一次情報マッピング）

`me.md` を読み込み、KWに関連する体験・数値を抽出する。

```
□ 使える数値（§2）
□ 使える体験談（§4）
□ 使える感情メモ（§5）
□ 使える具体エピソード（§6）
```

「競合が書けないが著者には書ける情報」を明示する。

```
- Lv1 顕在ニーズ：
- Lv2 潜在ニーズ（A 撤退層 / B 背中押し層）：
- Lv3 深層ニーズ：
- Lv4 検索シーン推定（5パターン）：

## ユーザーリサーチ
### 知恵袋の声
### SNS（X）の声

## 競合記事分析（除外後10本）
### 競合①：[タイトル]
- H2/H3構成：
- 強み：
- 弱み：
（競合②〜⑩を同形式で繰り返す）

## 一次情報マッピング（me.mdから使えるもの）
- 数値：
- 体験談：
- 感情メモ：

## 競合が書けない・著者だけが書けること

## 内部リンク計画
```

---

## 注意事項

- WebFetchで取得できないページはスキップし、取得できたページで分析を進める
- me.mdに記録のない体験・数値は「使えない」と明記する（捏造禁止）
- research.mdはユーザー確認後に `/outline` へ進む
