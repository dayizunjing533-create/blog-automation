# 筋トレ管理ツール (workout-tracker)

毎日のトレーニングを記録し、次回挑戦する重量・回数や種目のローテーションを自動で提案するPWAです。

## 主な機能

- **今日のトレーニング記録**: 現在のローテーションに応じたメニューと目標(重量・回数・セット数)を表示し、実績を記録
- **自動プログレッション**: 全セットで目標回数を達成すると、次回は回数を自動で増加。回数が上限に達すると重量を増やし回数をリセット（種目ごとに増加幅を設定可能）
- **種目ローテーション**: 複数のメニュー(プログラムデイ)を登録し、記録を保存するたびに次のメニューへ自動で切り替え
- **履歴**: 過去の記録を日付順に一覧表示、達成/未達バッジ付き
- **PWA対応**: ホーム画面に追加してオフラインでも利用可能

## データの保存先

サーバーは使用せず、ブラウザのIndexedDBに保存します（端末内完結、複数端末間の同期はありません）。

## セットアップ

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド (dist/ に出力)
npm run preview  # ビルド結果をローカルで確認
```

## 使い方

1. 「設定」タブで種目を登録（開始重量・回数の上限下限・増加幅などを設定）
2. 種目を組み合わせて「メニュー(プログラムデイ)」を作成（例: 上半身の日、下半身の日）
3. メニューをローテーション順に追加
4. 「今日」タブで表示されるメニューを記録・保存すると、自動的に次のメニューへローテーションが進む
