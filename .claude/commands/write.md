# /write コマンド｜骨格生成手順書 v3.1

## このコマンドの役割

PREP法またはPASONA法を使って本文の骨格を生成する。
ユーザーはその上から声・体験・感情を肉付けする。
生成物は「完成稿」ではなく「肉付け前のベース」。

---

## 前提条件

`drafts/article-XXX/outline.md` がユーザーの承認を得ていること。
未承認の場合は「先に /outline で構成案を承認してください」と返す。

---

## Step 1: 読み込むファイル（この順番で全て読む）

```
drafts/article-XXX/outline.md      ← 承認済みの構成＋一次情報の回答
drafts/article-XXX/research.md     ← 差別化ポイントの確認
me.md                               ← 著者の体験・数値（唯一の一次情報源）
assets/tone-sample.md              ← 著者の声・リズムの方向性（参照のみ）
assets/01_ng-words.md               ← 禁止表現リスト
assets/08_my-templates.md §2§7§8   ← PREP法・本文・まとめのルール
```

---

## Step 2: 差別化ポイントのH2独立チェック

research.md の採用済み差別化ポイントが、outline.md のH2に含まれているか確認する。
含まれていない場合は執筆前にユーザーに報告して確認を求める。

---

## Step 3: 使用する法則の選択

セクションの性質に応じて使い分ける。

| 使用場面 | 法則 |
|---|---|
| 通常のH3本文（説明・解説・リスト） | PREP法 |
| CTAセクション・購買・登録を促す箇所 | PASONA法 |
| リード文・まとめ | write.mdのStep4・Step6に従う |

---

## Step 4: リード文の骨格

```
【共感ライン】
→ 読者の心の声を「」で直引用するイメージでメモ書き。
  実際の文章はユーザーが書く。

【転換＋結論先出し】
→ 核心的な答えを1文で先出し。

【権威性】← me.md §2 の数値・属性をそのまま引用（捏造禁止）

【記事概要（箇条書き3点）】← outline.md の構成から抽出して自動生成

【アンサーファースト（1文）】← research.md の結論から引く

【CTA①】← outline.md に指定されたCTA文言をそのまま配置
```

---

## Step 5: 各H3の生成（PREP法）

```
P（Point）  : H3見出しの結論を1〜2文で先出し。ファクトベースで書く。
R（Reason） : なぜそうなのか、理由を1〜2文。論理ベースで書く。
E（Example）: me.md から該当する体験・数値を1つ引用してそのまま書く。
              → me.md に該当データがなければ【要一次情報】と書いて止まる。
P（Point）  : 読者が取れる具体的なアクションまたは結論で締める。
```

**禁止：**
- 体験Eから書き始める（必ずPから入る）
- me.md にない体験・数値を捏造する
- 感情表現・口語をClaude側で書く（そこはユーザーが肉付けする）

---

## Step 6: CTAセクションの生成（PASONA法）

リード直下・まとめ後のCTAはPASONA法で書く。

```
P（Problem）  : 読者が今抱えている問題を1文で明示する。
A（Agitation）: その問題を放置するとどうなるかを1文で煽る。
S（Solution） : このブログ・サービスが解決策になることを示す。
O（Offer）    : 具体的な提案（登録・読む・試す）を1文で出す。
N（Narrowing）: 今すぐ行動する理由（無料・簡単・リスクなし等）を添える。
A（Action）   : CTAリンクを配置する。
```

---

## Step 7: 表・チェックリストの生成

research.md と me.md のデータを使って自動生成する。

| 要素 | 最低数 |
|---|---|
| 表（2列以上） | 3枚 |
| 箇条書き | 5箇所 |
| チェックリスト | 1枚 |

---

## Step 8: まとめの構成

① 要点整理（表またはチェックリスト形式）← 自動生成
② 読者への一言（感情に寄り添う1〜2文）← メモ書きで方向性のみ示す
③ CTA②（PASONA法）← 自動生成

---

## Step 9: 禁止表現（01_ng-words.md 準拠）

- 「〜することが大切です」「〜することが重要です」
- 「非常に」「とても」（強調目的）
- 「本記事では〜について解説します」
- 「いかがでしたか」「ぜひ参考にしてみてください」
- 「〜という点が挙げられます」「〜と考えられます」

---

## Step 10: 生成後セルフチェック（出力前に必ず実行）

- [ ] 差別化ポイントが独立H2として含まれているか
- [ ] 全H3がP→R→E→Pの順になっているか
- [ ] CTAがPASONA法になっているか
- [ ] me.mdにない体験・数値を捏造していないか
- [ ] 表が3枚以上あるか
- [ ] NG表現が含まれていないか
- [ ] 1文が80文字を超えていないか（自動生成部分）
