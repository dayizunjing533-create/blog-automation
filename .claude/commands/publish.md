# /publish コマンド｜WordPress入稿準備手順書 v1.0

## このコマンドの役割

`final.md` を WordPress（Cocoon）に入稿するためのチェックリストと
入稿用データを生成する。実際の入稿はユーザーが行う。

---

## 前提条件

`drafts/article-XXX/final.md` が存在していること。

---

## Step 1: 読み込むファイル

```
drafts/article-XXX/final.md     ← 入稿対象
drafts/article-XXX/research.md  ← KW・内部リンク確認
```

---

## Step 2: 入稿データの生成

以下を一覧で出力する：

```
【入稿データ】

タイトル：
パーマリンク（slug）：（メインKWをローマ字またはハイフン区切りで）
メタディスクリプション：
カテゴリ：
タグ：
アイキャッチ画像：（テキストで指示のみ。生成はユーザーが行う）
```

---

## Step 3: WordPress入稿チェックリスト

```
【入稿チェックリスト】

本文
[ ] H2・H3の階層が崩れていないか
[ ] 内部リンクが全て正しいURLか（research.md §6 と照合）
[ ] CTAリンクのURLが正しいか（クラウドワークス等）
[ ] 表・箇条書きが正しく表示される形式か

SEO設定
[ ] タイトルをSEOタイトル欄に入力したか
[ ] メタディスクリプションを入力したか
[ ] パーマリンクを設定したか

Cocoon設定
[ ] アイキャッチ画像をアップロードしたか
[ ] カテゴリ・タグを設定したか
[ ] 公開日時を設定したか（予約投稿の場合）
```

---

## Step 4: 完了後の記録指示

入稿完了後にユーザーが行うこと：

```
topics/keywords.md に追記：
- 記事URL
- 公開日
- メインKW
- 狙い順位

topics/internal-link-map.md に追記：
- この記事から張ったリンク先
- この記事に張るべきリンク元（今後の記事で使う）
```

全項目を出力したら「入稿準備が完了しました」と伝えて止まる。
